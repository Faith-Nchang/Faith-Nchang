## Work in Progress

- **DataEvolyn** 🎯  
  _A compiler-like control plane for data evolution: catch breaking schema changes before they break your pipelines._

  DataEvolyn is a developer-focused data infrastructure platform that treats schemas, transformation models, and dependencies as one connected system. Inspired by compilers and static analysis, it shifts data reliability left, into development and CI/CD, instead of discovering broken pipelines after deployment.

  Features in development:
  - Dependency graph tracking how changes to tables, columns, data types, and APIs propagate across pipelines, analytics models, and apps
  - Compatibility analysis of proposed changes against existing downstream dependencies
  - Impact explanations that show exactly which systems a change would affect
  - Recommended and generated migration strategies
  - CI/CD integration to block breaking changes before they ship
